📐 算法说明

情绪识别与歌曲推荐两条完整链路，均为可解释的确定性算法

一、情绪识别算法（本地离线）

模型栈：面部分析使用 TensorFlow.js 版 face-api，三个模型共约 600KB，全部存放于 /models，运行时不访问任何外部网络。

  1. TinyFaceDetector：MobileNetV1 + SSD 架构，输入 416×416，输出人脸边界框与置信度；多层特征图负责小脸召回。
  2. FaceLandmark68TinyNet：回归 68 个人脸关键点，用于人脸对齐与可视化叠框。
  3. FaceExpressionNet：把对齐后的 64×64 灰度人脸送入卷积网络，最后一层 softmax 输出 7 类表情概率 （neutral / happy / sad / angry / fearful / disgusted / surprised）。

三层后处理增强：

  • 质量门控：检测分数 < 0.42 或人脸面积占画面 < 1.2% 的帧直接丢弃。
  • 时间平滑（EWMA）：w_k = score_k · e^(−(t−t_k)/900ms)，窗口 2 秒， p(i) = Σ w_k·p_k(i) / Σ w_k，抑制单帧抖动。
  • 连续情感映射：按 Russell 环形模型把 7 类离散概率投影为二维连续坐标 V = Σ p_i·V_i、A = Σ p_i·A_i，推荐阶段在此连续空间中计算距离，避免「跳变」。

二、歌曲推荐算法

第 1 步 · 目标画像：把当前 (V, A) 按策略搬到目标象限。

疗愈 heal : Vt = V + 0.42·(1−V) At = A + 0.30·(0.40−A) 共振 resonate: Vt = V At = A 提神 energize: Vt = V + 0.25·(1−V) At = A + 0.45·(1−A)

第 2 步 · 六因子打分（每首候选曲）：

simVA = exp(−((Vs−Vt)²+(As−At)²) / 2σ²) σ = 0.34 tag = 0.65·|tags∩T|/|T| + 0.35·[主导情绪标签命中] energy = 1 − |Es − At| tempo = 1 − min(1, |BPMs − (58+88·At)| / 70) mode = 大小调与目标效价是否同向 prof = exp(−‖歌曲特征 − 用户画像‖² / 2·0.3²) n ≥ 3 后生效 score = 0.40·simVA + 0.22·tag + 0.14·energy + 0.10·tempo + 0.06·mode + 0.08·prof

第 3 步 · MMR 多样性重排：避免 Top10 全是同一种歌。

pick = argmax[ λ·score(j) − (1−λ)·max_{i∈已选} sim(i,j) ] sim(i,j) = 0.6·exp(−V-A距离²/2·0.3²) + 0.4·Jaccard(tags) λ = 0.72

第 4 步 · 在线反馈学习：点击 ♥ 时 profile ← 0.85·profile + 0.15·songFeature，跳过的歌则向反方向微调， 使同一情绪下的推荐逐步贴合个人口味。

三、在线歌曲接口

本地曲库优先；点击「本地 + 在线 API」后调用 iTunes Search API （itunes.apple.com/search?media=music&entity=song，无需密钥）， 取回 30 秒官方试听片段。由于接口只返回元数据、不含音频特征， 系统用「检索情绪原型 + 标题/曲风关键词修正 + trackId 确定性抖动」推断其 V/A 特征， 并在结果中标注「在线」以便区分。

❔ 使用帮助

四种取像方式 · 三步出歌单

启动

必须在 HTTP 环境下运行（浏览器禁止 file:// 读取模型）。Windows 双击目录下的 start.bat，或命令行执行 python -m http.server 8080， 然后打开 http://localhost:8080。

四种输入方式

  • 图片：上传一张含人脸的 JPG/PNG，系统立即检测并显示情绪。
  • 视频：打开本地视频文件，逐帧追踪情绪变化。
  • 摄像头：实时采集，画面自动镜像（自拍视角）。首次使用需授权。
  • 拍照：把当前摄像头/视频画面定格成一张照片再分析，适合演示时固定结果。

推荐与播放

识别到情绪后歌单自动生成，「情绪疗愈 / 同频共振 / 提神充电」切换不同推荐策略； 点封面或 ▶ 播放；点 ♥ 会把偏好写入用户画像，参与后续排序。

演示模式

控制条右侧的下拉框可手动注入一种情绪（不依赖摄像头），用于在光线不佳或无人脸素材时 演示推荐链路——它与真实识别走的是同一套算法。
